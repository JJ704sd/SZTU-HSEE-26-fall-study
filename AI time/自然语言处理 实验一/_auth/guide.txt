from pathlib import Path  def read_text_checked(path):     failed = []     for encoding in ("utf-8", "utf-8-sig", "gb18030", "utf-16"):         try:             text = Path(path).read_text(encoding=encoding)             return text, encoding, failed         except UnicodeError as error:             failed.append({"encoding": encoding,                            "error": type(error).__name__})     raise UnicodeError(f"无法识别文件编码：{path}") 以C组GB18030文件为例： text, encoding, failed = read_text_checked("data/input_C_gb18030.txt") print("识别编码：", encoding) print("失败记录：", failed) print(text.splitlines()[0]) 实际输出： 识别编码： gb18030 失败记录： [{'encoding': 'utf-8', 'error': 'UnicodeDecodeError'},            {'encoding': 'utf-8-sig', 'error': 'UnicodeDecodeError'}] 【任务数据C：康复训练与全角字符】 这里的两次失败是有价值的诊断证据。不得使用errors="ignore"跳过错误，因为它会静默丢失字符。 3.3 实例三：Unicode规范化 C组文件中的“３０”是全角数字。NFKC规范化后变为“30”。 import unicodedata  before = "上肢抬举３０次" after = unicodedata.normalize("NFKC", before) print(before) print(after) 输出： 上肢抬举３０次 上肢抬举30次

规范化后必须检查医学信息是否仍然保留。不能用“只保留汉字”的正则清洗，因为它会删除128/78 mmHg、5 mg/片等有意义内容。 3.4 实例四：隐私字段掩码 import re  def mask_privacy(text):     text, mobile_n = re.subn(         r"(?<!\d)(1[3-9]\d)\d{4}(\d{4})(?!\d)",         r"\1****\2", text)     text, email_n = re.subn(         r"([A-Za-z0-9._%+-]{2})[A-Za-z0-9._%+-]*(@[A-Za-z0-9.-]+)",         r"\1***\2", text)     return text, {"mobile": mobile_n, "email": email_n}  sample = "电话13912345671，邮箱student1@example.com" print(mask_privacy(sample)) 输出： ('电话139****5671，邮箱st***@example.com', {'mobile': 1, 'email': 1}) 掩码只用于本实验中的合成数据。它不是经过临床验证的完整脱敏系统。 3.5 实例五：什么是断⾔ 断言（assertion）是程序中的“自动检查题”。程序员先写出对结果的预期：条件为True时，程序继续运行；条件为False时，Python立即报出AssertionError，告诉我们某项结果与预期不一致。 基本语法是： assert 需要检查的条件, "条件不成立时显示的提示" 例如，否定词“未”不能在清洗中被删除： clean_text = "患者未见异常放电。" assert "未" in clean_text, "清洗后丢失否定词‘未’" print("断言通过：否定词已保留") 正常输出： 断言通过：否定词已保留
