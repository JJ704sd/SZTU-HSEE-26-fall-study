# 深技大实验报告

写给检查实验过程与理解程度的任课教师：方法交代清楚，结果有依据，分析贴近本题，表达平实自然。按本次请求选择工作范围，不让一段润色触发整套报告流程。

## 按任务读取资料

| 本次任务 | 读取和完成范围 |
| --- | --- |
| 润色一句/一段，已有事实充分 | 读 [文风](references/writing.md) 和相关上下文，直接交付改稿；不搜索课程文件、不检查封面、不导出 PDF。需要核实某项事实时只读对应材料。 |
| 只调整排版，文字与数据已确认 | 读 [版式](references/layout.md)，保留原文、题号、数值和结论，仅修改授权范围的视觉呈现并验证。 |
| 新写/补全报告，或对照课程要求修订 | 从 [课程入口](references/course-profiles.md) 选择对应课程，只读该课程文件；写作读文风，生成文件时再读版式。 |
| 合并多次实验 | 读对应课程的提交组合与当前通知，先核对任务覆盖、页数及重复内容，再合并；原稿保留。 |

## 完整报告的做法

从用户指定的目录定位本次指导书、教师模板、评分/提交要求、实验记录与认可稿件。不要把所有课件、历史报告和参考文档读一遍。课程目录的定位线索在课程入口中。

材料承担不同作用：本次教师材料决定任务和提交要求，模板决定结构与样式，用户认可稿件决定本次文风与详略，当前代码、结果文件和本人记录支撑实验事实。较新的同次教师通知可修订旧要求；不能按文件名中的年份或“副本”判断新旧。与用户当前选择有具体冲突时说明影响，先完成不受影响的工作。

先在工作笔记中对应“要求—报告位置—材料来源”，再按模板编写。优先把任务、方法、结果与解释连起来；目的、原理和总结围绕这些内容取舍。保留用户已确认的文字；局部修改不重写已成立的其他部分。

读取 DOCX 包含表格和样式；PPT/PDF 中的图片也可能承载要求。不要把提取出的纯文本当作全部内容。写报告文件时优先填充模板副本，按课程要求导出；先规划有限页数如何覆盖内容，不靠压小字号塞页。

## 写作时的关键判断

- 数值、原文例句、实验条件、设备现象与当前材料一致。已有报告可以是同一次实验的有效记录，不因为文件名是“旧稿”就全部丢弃；先确认实验归属，再复用经核对的事实。
- 代码推演、编译、仿真、上板观察分别说清。缺少某项实测时仍完成可以写的原理、方法及已知结果；相应结论保留适用条件，不虚构成功、调试经历或本人已经理解的声明。
- 已有可重算的本地数据时，在隔离输出目录复核关键计算，不因旧检查报告“全通过”就照抄。先检查入口副作用，不覆盖原始数据和用户稿件；写报告本身不自动包含设备操作、长时间训练或环境变更。
- 依据课程规则处理思考题、AI 使用、签名和提交格式。只缺本人答案、签名或少量封面信息时，不暂停其他可写部分，也不把未完成的草稿称为可直接提交。

## 收尾

先核对必做内容、题号、单位、数据口径与分析，再通读文风和衔接。纯文字改稿直接交付文字；文件任务按版式说明实际导出并逐页查看，结构检查和视觉检查分别报告。

缺项按用户选定方式处理；未指定时保留干净的正文，在简短交付说明中列出具体待补位置和影响。只有用户明确要占位草稿时才将“待补”写进文内。交付稿件或文件及必要限制，不附机器评分或多轮自评。
