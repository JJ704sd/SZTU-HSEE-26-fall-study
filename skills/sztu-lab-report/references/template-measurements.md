# 本地模板测量快照

2026-10-20 对三类教师模板和机器学习现有报告的 OOXML 核实如下。属于模板事实，不等于学校对所有报告的统一规定。后续使用重新检查模板。

| 对象 | 实测值 | 使用方式 |
| --- | --- | --- |
| 页面 | `11906 × 16838 twips`，约 A4 纵向 | 保留模板 section。 |
| 页边距 | 上下 `1440 twips = 2.54 cm`，左右 `1800 twips = 3.175 cm` | 纸面可用宽约 `14.65 cm`。 |
| 页眉/页脚距离 | `851 / 992 twips`，约 `1.50 / 1.75 cm` | 保留原有设置，不为版面装饰增加页眉。 |
| 封面主标题 | 宋体、`22 pt`、加粗、居中，另有字符间距设置 | 沿用原段落，不能只设字号就宣称完全复刻。 |
| 封面字段主要文字 | 宋体，数字/英文多为 Times New Roman；主要 `14 pt`；`line=600, lineRule=auto` | 是 `2.5 倍行距`，不是 600 pt；有个别 run 差异，保持原 run。 |
| 学号/报告人、合作者/组号 | 两组分别各占同一行 | 不能改成四个单独字段行导致封面溢出。 |
| NLP 模板正文默认字号 | `10.5 pt`，默认两端对齐，字体有主题继承 | 只说明默认值；段落/字符样式或直接格式可覆盖。 |
| NLP 模板七节标题 | 样式 ID `3`，样式名 `heading 3`，加粗 `16 pt`，段前后各 `13 pt`，自动行距 `416/240 ≈ 1.733 倍` | 不凭样式 ID 猜级别；不要把另一个文档 ID `3` 的页眉样式套过来。 |
| 嵌入式、医院信息系统正文框 | 单列表格，网格约 `8323 twips`，带边框 | 有表格缩进和单元格边距，实际插图/嵌套表格可用宽小于纸面宽；读取本次容器后再定尺寸。 |

已有嵌入式实验五和机器学习实验三报告的正文常用宋体 `12 pt`；前者有黑体 `14 pt` 主标题及 `9 pt` 等宽代码，后者常用 `1.5 倍`行距。这是**历史样例**，不是教师明文规定，也不自动覆盖 NLP 模板样式。旧成稿存在封面内容延续到第二页的情形，不能把这种溢出当成格式要求。

模板路径见 [课程入口](course-profiles.md)。需要复刻本地旧模板或解释其具体属性时再查本页；不要默认把整份快照加载到每次改稿。
